# Tailwind 契約

**分類: 生成された契約リファレンス。** 本文は catalogue の解釈方法を説明します。生成された row は pin 済み theme package の compiled evidence を示すものであり、Tailwind setup tutorial ではありません。

「Tailwind token」は曖昧です。代わりに次の四つの用語を使います。

| Layer | 例 | Theme behavior |
|---|---|---|
| Utility name | `px-3`, `rounded-md`, `bg-primary` | source vocabulary のみ |
| Compile-time Tailwind value | `px-3` は固定 spacing value を出力 | module bundle に埋め込まれる |
| Runtime-backed utility | `bg-primary` は public `--p-*` variable への参照を出力 | facade runtime theme の変更に応答 |
| Public portable contract | 意図的に文書化された Wippy token または semantic utility | 対応する portable consumer に対して安定 |

Tailwind 3 は zero-runtime compiler です。utility name から runtime behavior を推測せず、出力された declaration を確認してください。

## Runtime semantic utility

正確な mapping の基準は、生成された utility catalogue です。現在の primary、surface、severity、text、content、highlight、radius utility を、出力 CSS と public variable dependency に基づいて分類します。

想定する category には semantic color、content border、muted text、および生成 source が mapping を確認した場合の `rounded-border` が含まれます。選択した preset と package version から生成された entry だけがここに現れます。

## Compile-time baseline

生成された catalogue は、constant に compile される spacing、sizing、default radius、font size、shadow、transition duration、timing function を別に記録します。

> Build-time baseline。この値は module bundle に埋め込まれ、facade theme の変更には応答しません。

compile-time value は `platform-invariant` と分類された property には有効です。別の facade theme で PrimeVue sibling に追従する必要がある property には不十分です。

現在同じ数値に解決されても、`rounded-md` と `rounded-border` は同等の契約ではありません。一方は compiled default、他方は runtime-backed です。現在値が等しくても semantic role が同じとは証明できません。

## 保護された mapping

module は shared preset を拡張できますが、次の保護された Wippy の意味を再定義してはいけません。

- Primary と surface family。
- Severity family。
- Text、content、highlight semantic。
- 公開済み portable-control semantic。

compliance check は実際の module Tailwind configuration を解決し、保護された mapping の互換性のない置換を拒否します。

## Custom sibling

portable custom sibling が使えるもの:

- 生成 catalogue に列挙された runtime-backed semantic utility。
- 選択した token manifest に列挙された direct public variable。
- `platform-invariant` と明示的に分類された property の compile-time utility。
- 本当に新しい structure のための module-local utility。

PrimeVue sibling に追従すると期待される property について、固定 dimension、radius、duration を copy してはいけません。public runtime semantic がなければ theme-contract gap を記録し、utility や token を作り出さないでください。
