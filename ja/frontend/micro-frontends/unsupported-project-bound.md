# サポート対象外のプロジェクト固定モジュール

Wippy がサポートするフロントエンドの契約は可搬です。プロジェクト私有のファサード CSS、私有クラス、またはその他のデプロイ固有のフロントエンド前提を意図的に必要とするモジュールは `UNSUPPORTED` です。

これは通常の例外ではありません。

- 標準のコンプライアンスは正確に `UNSUPPORTED` を返します。
- 標準の CI は失敗します。
- 再利用、テーマの可搬性、アップグレード、サポートは保証されません。
- モジュールの所有者が、消費するすべてのファサードと移行について責任を負います。

このモードを「非推奨」「部分的に準拠」「非準拠だが許容」などと呼ばないでください。正典のステータスは `UNSUPPORTED` です。

プロジェクト固定モードは上級者専用であり、クイックスタートや標準のレシピでは提示されません。アクセシビリティ、HTML の妥当性、セキュリティ、バックエンドのスキーマ要件を免除するものではありません。

プロジェクト全体が1つのデプロイ向けであるからといって、契約が黙って緩和されることはありません。サポート対象外というステータスは、プロジェクトのポリシーとモジュールのメタデータにおいて明示されなければならず、標準の CI 失敗は Wippy のサポート対象コンプライアンスワークフローの外で意図的に処理される必要があります。

モジュールルートの `wippy-fe.contract.json` に、以下の正確なフィールドと値でステータスを宣言してください。

```json
{
  "portability": "project-bound"
}
```

`mode` やその他のエイリアスは受け付けられません。このマーカーにより、標準のコンプライアンスコマンドは `UNSUPPORTED` を返し、失敗として終了します。免除を与えるものではありません。
