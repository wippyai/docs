# コントリビューション

Wippy は公開の [wippyai GitHub Organization](https://github.com/wippyai) で開発されています。現在のランタイムのリリース系列はアルファ版です。

## 安定性

ランタイムのリリース系列はアルファ版であり、公開リポジトリでは個別の互換性ポリシーや移行ポリシーを公開していません。アプリケーションで使用するランタイムとモジュールのバージョンを固定し、アップグレード前にリリースノートとドキュメントを確認してください。

## Issue と Pull Request

ドキュメントに関する Issue と Pull Request は [ドキュメントリポジトリ](https://github.com/wippyai/docs) で作成してください。公開ランタイムリポジトリは現在 [Pull Request](https://github.com/wippyai/runtime/pulls) を受け付けていますが、Issue は受け付けていません。パッチを含まないランタイムの不具合報告や提案には、公開されている組織の連絡先 [support@wippy.ai](mailto:support@wippy.ai) を使用してください。

コントリビューションは組織の [行動規範](https://github.com/wippyai/.github/blob/main/.github/CODE_OF_CONDUCT.md) に従う必要があります。

## セキュリティ

ドキュメントおよびランタイムのリポジトリでは、現在専用のセキュリティポリシーを公開していません。セキュリティ上の機密性がある問題は、公開 Issue を作成せず、[support@wippy.ai](mailto:support@wippy.ai) へ非公開で報告してください。

## サポート

[support@wippy.ai](mailto:support@wippy.ai) へお問い合わせください。
