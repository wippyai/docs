# Рецепт страницы

Страница — это приложение, собранное Vite и отображаемое в iframe `about:srcdoc`. Её маршрут и контекст хоста приходят из Wippy AppConfig и пакетов, а не из browser location.

## Обязательная настройка

1. Зарегистрируйте `view.page` и обслуживающие его записи файловой системы/роутера.
2. Включите необходимую доставку CSS. Оставьте включённым блок CSS `iframe` ради единообразия полос прокрутки по умолчанию.
3. Используйте `@wippy-fe/router` для маршрутизации Vue.
4. Установите PrimeVue и плагин Wippy для PrimeVue, если страница отображает любой PrimeVue-подобный элемент управления.
5. Используйте общий пресет Wippy для Tailwind, если страница пишет утилиты Tailwind.
6. Генерируйте внешние зависимости из зафиксированного снимка import map Web Host.
7. Собирайте в выходную директорию, выбранную развёртыванием.

```ts
import { createApp } from 'vue'
import PrimeVue from '@wippy-fe/theme/primevue-plugin'
import { createAppRouter } from '@wippy-fe/router'
import App from './App.vue'
import { routes } from './routes'

const app = createApp(App)
app.use(PrimeVue)
app.use(createAppRouter(routes))
app.mount('#app')
```

Сверяйте точные экспортируемые сигнатуры с выбранной версией пакета. Не создавайте локальный слой синхронизации роутера.

## Инъекция темы

Страница потребляет тему фасада, доставленную в её iframe. Используйте публичные компоненты PrimeVue, публичные переменные темы, документированные утилиты Tailwind с поддержкой во время выполнения и явно инвариантные утилиты времени компиляции.

Не используйте query-параметр хоста как фикстуру приложения. Контекстом хоста владеет AppConfig.

## Сборка

Вызывайте цель Make из репозитория модуля Wippy. Её рецепт формирует
вывод для развёртывания командой:

```text
npm run build -- --outDir <target> --emptyOutDir
```

`vite.config.ts` сохраняет относительное поведение ресурсов и не зашивает `outDir` развёртывания.

Не вызывайте напрямую нижележащую команду сборки пакетного менеджера или Vite.
В Windows вызывайте `make.bat`; он делегирует реализации `make.ps1` целевой
сборки.

См. [Контракт сборки и зависимостей](./build-system.md), [Топология платформы](../platform-topology.md) и [Конфигурация и регистр имён](./configuration-casing.md).
