# Tailwind Contract

«Tailwind-токен» — неоднозначный термин. Вместо него используйте эти четыре понятия.

| Слой | Пример | Поведение темы |
|---|---|---|
| Имя утилиты | `px-3`, `rounded-md`, `bg-primary` | Только словарь исходного кода |
| Значение Tailwind времени компиляции | `px-3` даёт фиксированное значение отступа | Встроено в бандл модуля |
| Утилита с привязкой ко времени выполнения | `bg-primary` даёт ссылку на публичную переменную `--p-*` | Реагирует на изменения темы фасада во время выполнения |
| Публичный переносимый контракт | Намеренно задокументированный токен Wippy или семантическая утилита | Стабилен для поддерживаемых переносимых потребителей |

Tailwind 3 — это компилятор без среды выполнения. Не выводите поведение времени выполнения из имени утилиты; изучайте генерируемое объявление.

## Семантические утилиты времени выполнения

Сгенерированный каталог утилит — источник истины для точных сопоставлений. Он классифицирует текущие утилиты primary, surface, severity, text, content, highlight и radius по генерируемому CSS и зависимости от публичных переменных.

Примеры предполагаемых категорий: семантические цвета, границы контента, приглушённый текст и `rounded-border`, если сгенерированный источник подтверждает это сопоставление. Запись появляется здесь, только если она сгенерирована из выбранного пресета и версий пакетов.

## Базовые значения времени компиляции

Сгенерированный каталог отдельно фиксирует отступы, размеры, радиусы по умолчанию, размеры шрифта, тени, длительности переходов и функции сглаживания, которые компилируются в константы.

> Базовое значение времени сборки. Оно встроено в бандл модуля и не реагирует на смену темы фасада.

Значения времени компиляции допустимы для свойств, классифицированных как `platform-invariant`. Их недостаточно для свойства, которое обязано следовать за соседним компонентом PrimeVue при другой теме фасада.

`rounded-md` и `rounded-border` — не эквивалентные контракты, даже если сейчас они разрешаются в одно и то же число: первое — скомпилированное значение по умолчанию, второе привязано ко времени выполнения. Совпадение текущих значений также не доказывает совпадения семантических ролей.

## Защищённые сопоставления

Модули могут расширять общий пресет. Они не должны переопределять защищённые значения Wippy для:

- Семейств primary и surface.
- Семейств severity.
- Семантики text, content и highlight.
- Опубликованной семантики переносимых элементов управления.

Проверка соответствия разрешает фактическую конфигурацию Tailwind модуля и отклоняет несовместимую замену защищённых сопоставлений.

## Пользовательские аналоги

Переносимый пользовательский аналог может использовать:

- Семантические утилиты с привязкой ко времени выполнения, перечисленные в сгенерированном каталоге.
- Публичные переменные напрямую, перечисленные в выбранном манифесте токенов.
- Утилиты времени компиляции для свойств, явно классифицированных как `platform-invariant`.
- Локальные утилиты модуля для действительно новых структур.

Он не может копировать фиксированные размеры, радиусы или длительности для свойств, которые должны следовать за соседним компонентом PrimeVue. Если публичной семантики времени выполнения нет, зафиксируйте пробел в контракте темы; не изобретайте утилиту или токен.
