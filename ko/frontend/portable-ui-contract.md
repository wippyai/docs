# 이식 가능한 UI 계약

이 페이지는 규범적 계약 참조입니다. 규칙 ID는 구현 튜토리얼이 아니라 검토 및 승인 요구사항을 정의합니다.

다음 ID가 각 규칙의 정식 소유자입니다.

## 이식성

### FE-PORT-001: 이식 가능이 기본값

규격을 준수하는 모듈은 모듈 수정이나 프로젝트 전용 facade 클래스 없이도 다른 규격 준수 facade 테마와 함께 동작합니다.

### FE-STYLE-001: 비공개 facade 의존성 금지

이식 가능한 모듈은 한 facade에만 정의된 임의의 클래스나 선택자를 요구할 수 없습니다. 공유 PrimeVue `.p-*` 테마 규칙은 비공개 클래스가 아닙니다. 한 모듈에 필요한 비-PrimeVue 스타일은 해당 모듈에 속하지만, 공유 컴포넌트와 의미를 따름으로써 최소화해야 합니다.

여러 자체 모듈이 같은 비-PrimeVue 스타일을 필요로 한다면 그 스타일은 facade에도 각 모듈에도 속하지 않습니다. [디자인 계층](./design-layer.md)을 참고하십시오.

## 컴포넌트와 어포던스

### FE-UI-001: 컨트롤 요구를 충족하면 PrimeVue 사용

PrimeVue가 필요한 의미, 상호작용, 의도한 어포던스를 제공한다면 모듈은 이를 사용해야 합니다.

### FE-UI-002: 데이터 형태는 어포던스가 아님

같은 값을 표현할 수 있다는 이유만으로 두 컨트롤이 동등해지는 것은 아닙니다. 의도한 어포던스가 시각적·행동적으로 토글이라면 `SelectButton`이 슬라이딩 3단 토글을 자동으로 대체하지는 않습니다.

### FE-UI-003: 의미와 어포던스가 같으면 외형도 같아야 함

동등한 컨트롤은 크기, 간격, 색상, 타이포그래피, 테두리, 그림자, 포커스, hover, disabled, invalid, 모션 동작을 공유해야 합니다. 사용자 정의 복합 컨트롤은 PrimeVue의 시각적 형제 컴포넌트를 명시하고 적용 가능한 모든 공유 런타임 속성을 상속합니다.

### FE-UI-004: PrimeVue 생략 범위는 좁음

모듈이 물리적으로나 의미적으로 PrimeVue와 유사한 것을 전혀 렌더링하지 않을 때만 PrimeVue를 생략할 수 있습니다. 차트만 있는 컴포넌트는 해당하지만 버튼이나 폼 필드가 있는 차트는 해당하지 않습니다.

### FE-UI-005: 컴포넌트 API를 만들어 내지 않음

문서화되지 않은 prop이나 동작은 지름길이 아닙니다. 존재하지 않는 positions prop을 만들어 PrimeVue `ToggleSwitch`를 3단 컨트롤로 바꿀 수는 없습니다. 필요한 어포던스를 제공하는 PrimeVue 컴포넌트나 조합이 없다면 검토된 사용자 정의 형제 절차를 따릅니다.

## Tailwind와 토큰

### FE-TW-001: Wippy Tailwind 지원

공유 Wippy 프리셋은 지원되는 빌드 시점 계약입니다. 모듈은 문서화된 유틸리티를 사용하고 도메인 레이아웃, 애플리케이션별 breakpoint, 장식, 새로운 시각화를 위해 확장할 수 있습니다.

### FE-TW-002: 컴파일된 값은 런타임 토큰이 아님

`px-3`, `rounded-md`, `duration-200` 같은 유틸리티는 일반적으로 상수로 컴파일됩니다. 일관된 기준선을 제공하지만 facade가 런타임 테마 변수를 바꿀 때 변경되지는 않습니다.

### FE-TW-003: 공유 형제의 외형은 런타임 의미를 따름

외형 속성이 여러 테마에서 PrimeVue 형제 컴포넌트를 따라야 한다면 문서화된 런타임 기반 시맨틱 유틸리티 또는 공개 토큰을 직접 사용합니다. 고정 유틸리티는 해당 속성이 명시적으로 `platform-invariant`로 분류된 경우에만 허용됩니다.

### FE-TW-004: 보호된 매핑은 의미 유지

모듈은 프리셋을 확장할 수 있지만 보호된 primary, surface, severity, text, content, highlight 또는 이식 가능한 컨트롤 의미를 호환되지 않게 재정의할 수 없습니다.

### FE-TOKEN-001: 모든 토큰은 존재해야 함

모든 `--p-*` 참조는 선택한 생성 manifest에 존재해야 합니다.

### FE-TOKEN-002: 토큰 이름은 추측 가능한 API가 아님

유추로 토큰을 만들지 마십시오. [토큰 카탈로그](./micro-frontends/token-catalogue.md) 또는 선택한 패키지 manifest를 검색합니다.

## 접근성

### FE-A11Y-001: 사용자 정의는 접근성 면제가 아님

사용자 정의 컨트롤 예외는 유효한 HTML, 키보드 상호작용, 포커스, 접근 가능한 이름, 상태, disabled 동작을 보존해야 합니다. 상호작용 요소를 중첩하면 안 됩니다.
