# Tailwind 계약

**분류: 생성 계약 레퍼런스.** 설명문은 카탈로그를 해석하는 방법을 안내합니다. 생성된 행은 고정 테마 패키지의 컴파일 증거를 보고하며 Tailwind 설정 튜토리얼이 아닙니다.

“Tailwind 토큰”이라는 표현은 모호합니다. 대신 다음 네 용어를 사용하세요.

| 계층 | 예시 | 테마 동작 |
|---|---|---|
| 유틸리티 이름 | `px-3`, `rounded-md`, `bg-primary` | 소스 어휘일 뿐 |
| 컴파일 시점 Tailwind 값 | `px-3`이 고정 간격 값을 출력 | 모듈 번들에 포함 |
| 런타임 기반 유틸리티 | `bg-primary`가 공개 `--p-*` 변수 참조를 출력 | facade 런타임 테마 변경에 반응 |
| 공개 이식성 계약 | 의도적으로 문서화한 Wippy 토큰 또는 의미 유틸리티 | 지원되는 이식 가능 소비자에게 안정적 |

Tailwind 3은 런타임이 없는 컴파일러입니다. 유틸리티 이름으로 런타임 동작을 추론하지 말고 출력된 선언을 검사하세요.

## 런타임 의미 유틸리티

정확한 매핑의 권위 있는 자료는 생성 유틸리티 카탈로그입니다. 현재 primary, surface, severity, text, content, highlight, radius 유틸리티를 출력 CSS와 공개 변수 의존성에 따라 분류합니다.

의도된 범주의 예로 의미 색상, content 테두리, muted text, 그리고 생성 소스가 매핑을 확인한 경우의 `rounded-border`가 있습니다. 선택한 프리셋과 패키지 버전에서 생성된 항목만 여기에 나타납니다.

## 컴파일 시점 기준값

생성 카탈로그는 상수로 컴파일되는 간격, 크기, 기본 반경, 글꼴 크기, 그림자, 전환 지속 시간, 타이밍 함수도 별도로 기록합니다.

> 빌드 시점 기준값. 이 값은 모듈 번들에 포함되며 facade 테마 변경에 반응하지 않습니다.

컴파일 시점 값은 `platform-invariant`로 분류된 속성에 유효합니다. 다른 facade 테마에서 PrimeVue 대응 컴포넌트를 따라야 하는 속성에는 충분하지 않습니다.

`rounded-md`와 `rounded-border`가 현재 같은 숫자로 해석되더라도 같은 계약은 아닙니다. 하나는 컴파일 기본값이고 다른 하나는 런타임 기반입니다. 현재 값이 같아도 의미 역할까지 같다는 증거는 아닙니다.

## 보호된 매핑

모듈은 공유 프리셋을 확장할 수 있지만 다음 Wippy 의미를 재정의하면 안 됩니다.

- Primary 및 surface 변수군
- Severity 변수군
- Text, content, highlight 의미
- 게시된 이식 가능 컨트롤 의미

컴플라이언스는 실제 모듈 Tailwind 설정을 해석하고 보호된 매핑을 호환되지 않게 교체하면 거부합니다.

## 커스텀 대응 컨트롤

이식 가능한 커스텀 대응 컨트롤은 다음을 사용할 수 있습니다.

- 생성 카탈로그에 있는 런타임 기반 의미 유틸리티
- 선택한 토큰 매니페스트에 있는 직접 공개 변수
- 명시적으로 `platform-invariant`로 분류된 속성용 컴파일 시점 유틸리티
- 실제로 새로운 구조를 위한 모듈 로컬 유틸리티

PrimeVue 대응 컴포넌트를 따라야 하는 속성에 고정 크기, 반경, 지속 시간을 복사하면 안 됩니다. 공개 런타임 의미가 없다면 테마 계약 공백을 기록하고 유틸리티나 토큰을 임의로 만들지 마세요.
