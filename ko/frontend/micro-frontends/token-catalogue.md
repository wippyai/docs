# 토큰 카탈로그

> 유추로 토큰 이름을 만들지 마세요. 이 카탈로그나 선택된 패키지 매니페스트를 검색하세요.

이 페이지는 `@wippy-fe/theme`의 구조화된 토큰 소스를 체크인된 형태로 투영한 것입니다. 규범적 서술은 Wippy 문서에 있으며; 토큰 이름, 값, 소비자, 소스 출처는 패키지 소스에서 생성됩니다.

생성되는 모든 행에는 다음이 포함됩니다:

- 정확한 CSS 변수 이름과 안정적 식별자. 검토된 시맨틱/컴포넌트
  계약은 작성된 ID를 사용하고; 팔레트와 상속된 엔트리는 공개 변수 이름에서
  결정론적으로 파생된 ID를 사용합니다.
- 선택된 매니페스트가 공개하는 경우 공식 PrimeVue 또는 PrimeUIX 경로.
- 레이어와 시맨틱 용도.
- 기본, 라이트, 다크 매핑.
- 브라우저에서 수용된 런타임 커버리지와 분리된 선언 커버리지.
- 이식 가능한 커스텀 형제 계약 소비자와 분리된 PrimeVue CSS
  소비자.
- 선택된 매니페스트의 안정성; 없는 라이프사이클 메타데이터는 임의로
  만들어내지 않습니다.

스냅샷 헤더에는 `schemaVersion`, `packageVersion`, `implementationRelease`, Tailwind, PrimeUI 플러그인, PrimeVue, PrimeUIX 패키지 버전, 그리고 소스 해시가 기록되어야 합니다. 패키지 버전과 매니페스트 스키마 버전은 서로 다른 값입니다.

선언되었다고 해서 유효한 것은 아닙니다. 생성된 패키지 커버리지는
`inherited`로 유지되며; 게시하려면 커밋된 모든 수용 요구사항에 대해 외부의,
콘텐츠 해시가 적용된 계산 스타일 및 시각적 증거가 별도로 필요합니다.
로컬 증거는 체크인된 이 카탈로그에 투영되지 않습니다. 임시
애니메이션 변수는 Wippy가 의도적으로 공개하지 않는 한 내부용으로
분류됩니다.

## 유효 계약 원장

토큰 추가는 제안된 이름이 아니라 증거에서 시작합니다. Button, 폼 필드,
ToggleSwitch 및 그 포커스 상태에서 감사된 모든 appearance 선언이나 Tailwind
유틸리티에 대해, 생성된 원장은 안정 ID, 소스 파일 또는 업스트림 객체,
선택자 또는 PrimeVue 경로, 작성된 속성/유틸리티, 가능한 경우 해석된 값,
참조된 런타임 변수, 시맨틱 검토 상태, 뮤테이션 상태, 판정, 소스 증거를
기록합니다.

`runtime-covered-existing`은 해당 선언이 공개 런타임 변수에 의존한다는,
방출된 CSS에 대한 정적 증명입니다. 브라우저 수용이 아닙니다. 계산 스타일
뮤테이션이 성공할 때까지 토큰 커버리지는 `inherited`로, 뮤테이션은
`pending-browser-proof`로 유지됩니다.

허용되는 판정은 다음과 같습니다:

- `runtime-covered-existing`
- `compile-baseline-platform-invariant`
- `compile-baseline-insufficient`
- `partly-covered-needs-semantic-indirection`
- `official-semantic-gap-used`
- `official-component-gap-used`
- `literal-needs-contract`
- `internal-transient`
- `declared-unconsumed`
- `unused-upstream`
- `legacy`
- `semantic-mismatch`
- `name-collision`

새 공개 토큰은 해당 속성이 런타임에 변경되어야 하고, 현재 유틸리티가 상수로 컴파일되며, 일치하는 기존 공개 시맨틱이 없고, 정확한 업스트림 경로가 검증되었거나 Wippy 확장이 별도로 검토되었으며, 실제 Wippy CSS 소비자가 존재하고, 뮤테이션 테스트가 예상된 계산 속성의 변경을 증명할 때만 허용됩니다.

현재 값이 같다고 해서 시맨틱이 같은 것은 아닙니다. 특히 일반 콘텐츠 반경은 명시적인 구조적 관계 없이 모든 컨트롤의 반경 계약이 될 수 없습니다.

## 런타임 증거

생성된 원장은 보이는 브라우저 테스트가 실제 컴포넌트를 렌더링하고, 원래
계산 속성을 읽고, 토큰을 변경하고, 예상된 속성이 바뀌는지 검증하고, 값을
복원할 때까지 런타임 증명을 `pending-browser-proof`로 기록합니다. 보류 중인
기록은 런타임 수용 증거가 아닙니다.

게시하려면 팔레트 색상 이상을 바꾸는 대체 테스트 테마가 추가로 필요합니다:
선택된 반경, 폼 필드 패딩, 포커스 기하, ToggleSwitch 기하, 그리고
`theme-variable`로 분류된 모든 그림자 또는 모션 속성. 이는 색상 커버리지가
기하 관련 공백을 가리는 것을 방지합니다.
