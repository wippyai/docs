# 지원되지 않는 프로젝트 종속 모듈

Wippy가 지원하는 프론트엔드 계약은 이식 가능합니다. 프로젝트 전용 파사드 CSS, 비공개 클래스, 또는 배포에 특수한 다른 프론트엔드 가정을 의도적으로 요구하는 모듈은 `UNSUPPORTED`입니다.

이는 일반적인 예외가 아닙니다:

- 표준 준수 검사는 정확히 `UNSUPPORTED`를 반환합니다.
- 표준 CI가 실패합니다.
- 재사용, 테마 이식성, 업그레이드, 지원이 보장되지 않습니다.
- 모든 소비 파사드와 마이그레이션에 대한 책임은 모듈 소유자에게 있습니다.

이 모드를 "권장하지 않음", "부분 준수", "비준수이나 허용됨"으로 표기하지 마세요. 정식 상태는 `UNSUPPORTED`입니다.

프로젝트 종속 모드는 상급자 전용이며 퀵스타트나 표준 레시피에서 소개되지 않습니다. 접근성, HTML 유효성, 보안, 백엔드 스키마 요구 사항을 면제할 수 없습니다.

프로젝트 전체가 하나의 배포를 위한 것이라 해도 계약이 조용히 완화되지는 않습니다. 지원되지 않는 상태는 프로젝트 정책과 모듈 메타데이터에 명시되어야 하며, 표준 CI 실패는 Wippy가 지원하는 준수 워크플로 바깥에서 의도적으로 처리되어야 합니다.

모듈 루트의 `wippy-fe.contract.json`에 아래의 정확한 필드와 값으로 상태를
선언하세요:

```json
{
  "portability": "project-bound"
}
```

`mode`나 다른 별칭은 허용되지 않습니다. 이 표시는 표준 준수 명령이
`UNSUPPORTED`를 반환하고 실패로 종료하게 만들 뿐, 면제를 부여하지 않습니다.
