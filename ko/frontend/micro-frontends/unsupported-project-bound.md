# 지원되지 않는 프로젝트 종속 모듈

**분류: 규범 정책 레퍼런스.** 프로젝트가 선택한 컴플라이언스 워크플로의 마커와 필수 결과를 정의합니다. 공개 패키지군은 이 워크플로를 실행 가능한 CLI로 제공하지 않습니다.

Wippy가 지원하는 프런트엔드 계약은 이식 가능합니다. 프로젝트 비공개 facade CSS, 비공개 클래스 또는 배포에 종속된 다른 프런트엔드 가정을 의도적으로 요구하는 모듈은 `UNSUPPORTED`입니다.

이는 일반적인 예외가 아닙니다. 프로젝트 컴플라이언스 워크플로는 다음 결과를 강제해야 합니다.

- 표준 컴플라이언스 결과가 정확히 `UNSUPPORTED`입니다.
- 표준 CI가 실패합니다.
- 재사용, 테마 이식성, 업그레이드, 지원이 보장되지 않습니다.
- 모듈 소유자가 모든 소비 facade와 마이그레이션을 책임집니다.

이 모드를 “권장하지 않음”, “부분 준수”, “허용된 비준수”라고 표시하지 마세요. 정식 상태는 `UNSUPPORTED`입니다.

프로젝트 종속 모드는 고급 사용자 전용이며 빠른 시작이나 표준 레시피에 제시되지 않습니다. 접근성, HTML 유효성, 보안 또는 백엔드 스키마 요구 사항을 면제할 수도 없습니다.

프로젝트 전체가 단일 배포만을 목적으로 한다고 해서 계약이 암묵적으로 완화되지는 않습니다. 지원되지 않는 상태를 프로젝트 정책과 모듈 메타데이터에 명시해야 하며, 표준 CI 실패는 Wippy의 지원 컴플라이언스 워크플로 외부에서 의도적으로 처리해야 합니다.

모듈 루트의 `wippy-fe.contract.json`에 아래와 정확히 같은 필드와 값을 선언합니다.

```json
{
  "portability": "project-bound"
}
```

`mode` 및 다른 별칭은 허용되지 않습니다. 컴플라이언스 워크플로는 이 마커에 대해 `UNSUPPORTED`를 반환하고 실패 상태로 종료해야 합니다. 마커가 면제를 부여하는 것은 아닙니다. 공개 `@wippy-fe/*` 0.0.56 패키지군은 애플리케이션 컴플라이언스 CLI를 제공하지 않으므로, 프로젝트가 선택한 컴플라이언스 워크플로에서 이 게이트를 구현해야 합니다.
