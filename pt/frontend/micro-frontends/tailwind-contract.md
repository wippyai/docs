# Contrato Tailwind

“Token Tailwind” é ambíguo. Use estes quatro termos em vez disso.

| Camada | Exemplo | Comportamento de tema |
|---|---|---|
| Nome de utilitário | `px-3`, `rounded-md`, `bg-primary` | Apenas vocabulário de origem |
| Valor Tailwind de tempo de compilação | `px-3` emite um valor de espaçamento fixo | Embutido no bundle do módulo |
| Utilitário runtime-backed | `bg-primary` emite uma referência a uma variável pública `--p-*` | Responde a mudanças de tema em runtime da facade |
| Contrato público portável | Um token Wippy ou utilitário semântico deliberadamente documentado | Estável para consumidores portáveis suportados |

O Tailwind 3 é um compilador sem runtime. Não deduza comportamento de runtime a partir do nome de um utilitário; inspecione a declaração emitida.

## Utilitários semânticos de runtime

O catálogo gerado de utilitários é a autoridade para os mapeamentos exatos. Ele classifica os utilitários atuais de primary, surface, severity, text, content, highlight e radius pelo CSS que emitem e pela dependência de variável pública.

Exemplos das categorias pretendidas incluem cores semânticas, bordas de conteúdo, texto atenuado e `rounded-border` quando a fonte gerada confirma seu mapeamento. Uma entrada aparece aqui apenas quando é gerada a partir do preset e das versões de pacote selecionados.

## Linha de base de tempo de compilação

O catálogo gerado registra separadamente espaçamento, dimensionamento, raios padrão, tamanhos de fonte, sombras, durações de transição e funções de temporização que compilam para constantes.

> Linha de base de tempo de build. Este valor é embutido no bundle do módulo e não reage a uma mudança de tema da facade.

Valores de tempo de compilação são válidos para propriedades classificadas como `platform-invariant`. Eles são insuficientes para uma propriedade que precisa acompanhar um irmão PrimeVue sob outro tema de facade.

`rounded-md` e `rounded-border` não são contratos equivalentes mesmo que hoje resolvam para o mesmo número: um é um padrão compilado e o outro é runtime-backed. Valores atuais iguais também não provam papéis semânticos iguais.

## Mapeamentos protegidos

Módulos podem estender o preset compartilhado. Eles não devem redefinir significados Wippy protegidos para:

- Famílias primary e surface.
- Famílias de severity.
- Semânticas de text, content e highlight.
- Semânticas publicadas de controles portáveis.

A conformidade resolve a configuração Tailwind real do módulo e rejeita a substituição incompatível de mapeamentos protegidos.

## Irmãos customizados

Um irmão customizado portável pode usar:

- Utilitários semânticos runtime-backed listados no catálogo gerado.
- Variáveis públicas diretas listadas no manifesto de tokens selecionado.
- Utilitários de tempo de compilação para propriedades explicitamente classificadas como `platform-invariant`.
- Utilitários locais do módulo para estrutura genuinamente nova.

Ele não pode copiar dimensões, raios ou durações fixas para propriedades que devem acompanhar seu irmão PrimeVue. Se não existir nenhuma semântica pública de runtime, registre uma lacuna no contrato de tema; não invente um utilitário ou token.

## Catálogo gerado de utilitários

O snapshot versionado é gerado a partir de:

- A versão exata do Tailwind selecionada por `@wippy-fe/theme`.
- A versão exata de `tailwindcss-primeui`.
- O `tailwind.config.ts` compartilhado do Wippy.
- As extensões do Wippy.
