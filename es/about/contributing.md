# Contribuir

Wippy se desarrolla públicamente en la [organización wippyai de GitHub](https://github.com/wippyai).
La línea de releases del runtime está actualmente en fase alpha.

## Estabilidad

La línea de releases del runtime está en alpha y los repositorios públicos no publican
una política de compatibilidad o migración separada. Fija las versiones del runtime y
los módulos de cada aplicación, y revisa las notas de release y la documentación antes
de actualizar.

## Issues y pull requests

Abre issues y pull requests de documentación en el [repositorio de documentación](https://github.com/wippyai/docs).
El repositorio público del runtime acepta actualmente [pull requests](https://github.com/wippyai/runtime/pulls),
pero no issues. Para informar de un defecto o propuesta del runtime sin un parche,
usa el contacto publicado de la organización: [support@wippy.ai](mailto:support@wippy.ai).

Las contribuciones deben seguir el [Código de conducta](https://github.com/wippyai/.github/blob/main/.github/CODE_OF_CONDUCT.md)
de la organización.

## Seguridad

Los repositorios de documentación y runtime no publican actualmente una política de
seguridad específica. Comunica los problemas sensibles de forma privada a
[support@wippy.ai](mailto:support@wippy.ai) en vez de abrir un issue público.

## Soporte

Contacta con [support@wippy.ai](mailto:support@wippy.ai).
